Meditor

Detects news articles and clips them to your Glide webhook.

Webhook

Each clip is sent as a JSON POST to this URL.

In Glide, open the workflow's Webhook trigger and copy its bearer token. Meditor sends it as an Authorization: Bearer … header. Leave this empty if your trigger has no token. It's stored only on this device and never synced.

Payload format 
{
  "url": "https://example.com/2026/11/09/story",
  "title": "Headline of the article",
  "image": "https://example.com/lead-image.jpg",
  "published_date": "2026-11-09T14:30:00.000Z",
  "authors": ["Jane Doe", "John Roe"]
}

image is the lead image's absolute URL. published_date is ISO 8601 in UTC, or an empty string when the page has no date.

Auto-send

Send articles automatically as soon as you open them, without clicking the toolbar button.

Minimum confidence 70%

Only pages scored at or above this confidence are sent. Each URL is sent once; you can always resend from the popup.
